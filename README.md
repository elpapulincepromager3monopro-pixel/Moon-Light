# Moon Light
Asistente web: HUD premium, control por cámara y voz, gestor de archivos local y conexión a la nube (NVIDIA NIM / OpenRouter / OpenAI).

## Cómo usarlo
- **NUBE/CEREBRO**: configura una API para dominio total de materias (o usa el modo local).
- **ARCHIVOS**: abre una carpeta y MOON LIGHT puede crear, editar, mejorar y borrar archivos SOLO dentro de ella.
- **App**: en Chrome, pulsa el ícono de instalar en la barra de direcciones para usarla como aplicación.
